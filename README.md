# glTF Animation Example

Example of skeletal animation using cgltf, cglm, SDL2, libepoxy, and stb_image.

The keybinds are:
- wasd: Move around
- mouse: Look around
- scroll wheel: Scale model
- arrow keys: Rotate model
- c: Switch betwen textured and color
- v: Switch between unlit and phong lighting
- g: Enable/disable window mouse grabbing
